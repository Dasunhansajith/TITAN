# ⚡ TITAN — Clean 3D Starter Template

A clean, minimal starting boilerplate configured with **React 19**, **Vite**, **Three.js**, **React Three Fiber (R3F)**, **@react-three/drei**, **GSAP ScrollTrigger**, **Tailwind CSS v4**, and **Lucide React**.

---

## 🛠️ Installed Packages

- **React 19** (`react`, `react-dom`)
- **Vite 6** (`vite`, `@vitejs/plugin-react`)
- **Three.js** (`three`)
- **React Three Fiber** (`@react-three/fiber`)
- **Drei Helpers** (`@react-three/drei`)
- **GSAP & ScrollTrigger** (`gsap`)
- **Tailwind CSS v4** (`tailwindcss`, `@tailwindcss/vite`)
- **Lucide React** (`lucide-react`)
- **React Router** (`react-router-dom`)

---

## 🚀 Running the Project

```bash
# Start Development Server
npm run dev

# Build for Production
npm run build

# Preview Production Build
npm run preview
```
